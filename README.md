# ⚡ TechPulse — High-Density Technical Intelligence Dashboard

Website link: https://sergitm12.github.io/personal-news-engine/

A lightweight, high-performance Progressive Web App (PWA) engineered to ingest, categorize, and synthesize real-time global technical developments across hardware, software architecture, automation, and tech economics.

Built with a strict focus on **high information density, zero visual noise, and zero-latency client-side execution**.

---

### 🏛️ Engineering & Architecture Highlights

- **Client-Side Live Feed Pipeline:** Eliminates backend database overhead and hosting costs by utilizing client-side XML parsing (`DOMParser`) over resilient CORS bridges, streaming live RSS feeds directly to the user.
- **Decoupled AI Synthesis (Google Gemini API):** Integrates Gemini 2.0 Flash to convert raw technical announcements into structured, high-signal technical breakdowns and strategic impact evaluations on demand.
- **Design System & UX Engineering:** Built using automated design token extraction (Linear-inspired slate palette), featuring a multi-column Bento Grid layout engineered for rapid cognitive scanning.
- **Zero-Build PWA Footprint:** Fully responsive, offline-capable PWA installable on iOS and Android with zero ongoing server or deployment fees (100% static GitHub Pages hosting).
- **Interactive State Persistence:** Utilizes local storage for tracking read states, article bookmarking, and local API key management.

### 🎯 Core Knowledge Streams

1. **Silicon & Microarchitecture:** Lithography (EUV/High-NA), RISC-V developments, fab expansions, packaging (CoWoS), and semiconductor market shifts.
2. **Systems & Software Engineering:** Cross-platform engine optimizations, compiler updates, WebAssembly, and low-level system APIs.
3. **Enterprise & Local Automation:** Matter/Thread protocols, Industrial IoT specifications, and workflow automation.
4. **Macro Tech & Semiconductor Markets:** Capital expenditure analysis, foundry logistics, and major tech equity earnings wire.

---

### 🛠️ Tech Stack

- **Frontend:** Vanilla JS (ES6+), HTML5, Tailwind CSS (CDN)
- **AI Integration:** Google Gemini API (`gemini-2.0-flash`)
- **Data Ingestion:** Native DOMParser, RSS/Atom XML streams, Fetch API
- **Deployment & Hosting:** GitHub Pages (Static PWA)
